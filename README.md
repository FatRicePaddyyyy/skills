# skills

## 公開スキル

```bash
gh skill install FatRicePaddyyyy/skills user-context
gh skill install FatRicePaddyyyy/skills verbalize
gh skill install FatRicePaddyyyy/skills structure-first
```

- `user-context` — 会話の関心事・手法・ドメイン／開発暗黙知を `PROFILE/` に機会収穫
- `verbalize` — 違和感・気づきを言語化し、受け手に伝わる説明へ落とす
- `structure-first` — 文章を書く前に構造（骨組み）を先に決める

## よく使う外部 Skills

```bash
gh skill install github/gh-stack
gh skill install anthropics/skills skill-creator
```
